# Fireside changelog

## 0.1.0-beta2 (not released yet)
- Right-click any object to craft another, even one you already carry.
- Crafting no longer needs the profession window open: if it is closed, the click opens it and crafts in one go.
- `Esc` closes the panel like any other game window.
- Placing: the game reports a campfire from about 100 yards away, farther than you can place from - the tooltip now says to walk up to the fire.
- `/fire log on` also records the game's own error messages, for bug reports.

## 0.1.0-beta1
- First release: camping objects panel, one row per profession, crafting from the panel, materials and tools in the tooltip.
- Minimap button that pulses and chimes when a campfire is in range; shift-click it to reload the UI.
- Welcoming Campfire countdown and Camp Benefits read-out.
- Recipe data for every camping object in the game, harvested from a live beta client.
